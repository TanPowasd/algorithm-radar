# 算法雷达站 📡

比较多个 AI（或同一 AI 的不同版本 / 提示词策略）在洛谷题目上的解题能力。数据以「一条条提交记录」的形式录入，页面自动生成 **能力雷达图**、**AI × 题目覆盖矩阵** 和 **可筛选明细表**。

## 快速开始

1. 双击 `start.bat`（或在本目录运行 `python server.py`）
2. 浏览器会自动打开 `http://127.0.0.1:8471/`
3. 点右上角「提交记录」录入数据

## 功能

- **提交记录**：AI 名称、版本/策略、思考等级、洛谷题号、结果（AC/WA/TLE/MLE/RE/CE/未解出）、尝试次数、用时、日期、备注
- **自动抓取题目信息**：输入题号后自动从洛谷获取题目名、难度（八档）、算法标签，并自动归类到算法大类（动态规划 / 图论 / 数学 / 搜索……）；被洛谷风控拦截或信息不对时可手动覆盖
- **能力雷达图**：每个「AI × 策略」组合一条多边形，轴值 = AC 率；可在「按算法类别 / 按难度等级」两种轴之间切换；点击图例可显示/隐藏系列
- **模型 × 思考等级 平均分柱状图**：按「模型 + 思考等级」组合展示所有有分数轮次的平均分，从高到低排列
- **AI × 题目覆盖矩阵**：一眼看出谁没做、谁没过；单元格悬停可看详情；支持首轮均分 / 最终轮均分视图
- **明细表**：按 AI 组合 / 难度 / 类别 / 结果 / 关键字筛选，点表头排序，支持编辑、删除
- **导出 / 导入 JSON**：数据备份与迁移（仅管理员可见）

## 权限与审核

- **游客**（默认，无需登录）：可以**新增**记录（提交后为「待审核」状态，**不进入统计**）；**不能**删除、编辑记录，**不能**导出/导入
- **管理员**：点右上角「管理员登录」，输入**用户名 `TanPowasd`** 与密码；可删除/编辑记录、审核游客提交（通过后计入统计）、导出/导入
- **密码存储**：代码中**不含明文密码**，仅存 SHA-256 哈希（`public/app.js` 顶部的 `ADMIN_PASSWORD_HASH`）；登录时对输入做同算法哈希比对。修改密码 = 用任意 SHA-256 工具算出新密码哈希后替换该常量
- ⚠️ 权限基于前端 localStorage + 前端哈希校验，适用于本地/家庭使用，**不具备真正的安全隔离**（懂技术的人可绕过）；如需严格权限请另行设计后端鉴权

## 数据存哪里？

- 记录和题目缓存保存在**当前浏览器的 localStorage** 中（本机、本浏览器）。
- 洛谷题目信息通过本地服务器代理抓取（洛谷接口有跨域限制和风控，不能从浏览器直接抓），题目缓存在服务器内存中，重启服务后由浏览器缓存兜底。
- ⚠️ 清除浏览器站点数据会丢失记录。请养成习惯，定期点「导出 JSON」备份；换浏览器/设备用「导入 JSON」恢复。

## 部署到 Vercel（可选）

项目已适配 Vercel：静态文件在 `public/`，洛谷代抓为 Serverless 函数（`api/`）。

1. 把代码推到 GitHub 仓库
2. 到 [vercel.com](https://vercel.com) 用 GitHub 登录 → **New Project** → 导入该仓库
3. Framework Preset 选 **Other**，其余默认，点 **Deploy**
4. 部署完成后获得 `https://<project>.vercel.app` 地址

> 提示：Vercel 免费版 Serverless 函数有冷启动与执行时长限制；洛谷风控偶发拦截时仍可手动填写题目信息（与本地版一致）。

## 数据口径说明

- **难度档位**采用洛谷官方八档：暂无评定 / 入门 / 普及− / 普及/提高− / 普及+/提高 / 提高+/省选− / 省选/NOI− / NOI/NOI+/CTSC。
- **算法大类**由洛谷题目的算法标签沿标签树向上归类（标签表 version：zh-CN/2026082918）；无标签的题记入「其他/未标注」。
- 雷达图轴值 = AC 记录数 ÷ 该 AI 在该轴上的作答记录数；**未作答的轴显示为空缺，不按 0% 计**，避免拉低均值造成误导。
- 「AI 组合」= AI 名称 + 版本/策略（如 `GLM-4.7 · 深度思考`），同一 AI 的不同策略各自成系列。

## 已知限制

- 洛谷有反爬风控：偶发 302 循环或拦截时会返回错误提示，此时手动填写题目信息即可；题目信息抓取成功后会缓存在浏览器中，不会重复请求。
- 服务器仅监听 `127.0.0.1`，只在本机可用（设计如此，数据不出本机）。
