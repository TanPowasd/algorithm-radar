# 阅读界面与验收

本轮调整首页评测页签、导航与阅读布局。后端、数据库、API、管理员权限与统计口径保持原有实现。

## 主题与阅读

- 设置提供跟随系统、白天、黑夜、暖色四种主题；首次访问跟随系统，历史 `radar.theme` 偏好继续生效。
- 黑夜页面、主面板、侧栏和顶栏底色均为 `#000000`，次级控件用浅层背景和边线区分。正文、说明和成绩采用高对比文字。
- 正文字号可选 16、18、20px，说明文字随字号调整，至少 14px；矩阵保留等宽数字与分数颜色。
- 清爽 / 紧凑调整留白、行间距和圆角；VS Code 提供紧凑目录侧栏和状态栏，采用同一套主导航。四种主题独立于风格；全宽 / 居中沿用 `radar.widthMode`。

## 功能归类

- 主导航移至侧栏，可收起成图标栏；手机通过顶栏菜单展开。
- 顶栏固定提供桌面侧栏的收起 / 展开按钮，收起、刷新与切换页面后仍可展开。VS Code 底部状态栏采用当前主题的面板底色、次级文字和边线。
- 首页保留 AI 分数、rating、测评明细三个评测页签，比赛集中在侧栏入口。旧 `?v=arena` 链接转到比赛目录，带 `competition` 时转到对应比赛详情；不重复嵌入同一比赛页面。
- 滚榜回放、推荐提示词、贡献者收纳在「资料与回放」。管理员的审核、用户管理、发布与导入集中在管理分组。
- 首页「筛选」默认折叠，分数与 rating 页放入矩阵工具栏，测评明细页保留独立入口；仅选择模型或贡献者后显示范围摘要。展开状态保存在当前设备。
- 五种成绩口径收纳为一个下拉框，排名 / 对比 / 矩阵继续保留。
- 「设置 → 功能显示」可单独隐藏比赛、测评明细、资料入口、统计、图例、思考等级和快捷键按钮。
- 隐藏当前测评页签时回退至 rating；页签方向键和数字快捷键只能选择可见页签。显示开关不作为权限控制，也不删除数据。
- 设置中的导出和运行读数沿用原接口。设置支持 Tab 焦点循环、方向键切换分类和 Escape 关闭。

## 保存与恢复

新增 `radar.ui.preferences.v1` 保存风格、字号、侧栏和显示开关，`radar.analysisFiltersExpanded` 保存筛选区状态。
`motion` 默认跟随系统，可在「设置 → 外观 → 切换动画」关闭；关闭状态与其他阅读偏好一起保存在本机。
读取时校验字段，损坏或不可用的存储回退至默认。首次绘制前应用主题与阅读偏好；恢复默认将主题设为跟随系统、风格设为清爽、字号设为 16px、宽度设为全宽，并恢复默认功能显示。

## 内容、演示与交互

- 提示词页优先展示题目、简短摘要和复制操作；完整模板、使用步骤与评测口径默认折叠。点击索引里的查看会选题并展开正文。
- 索引移除重复的长提示词预览，每页只挂载 20 题；搜索及难度、类型筛选从第一页开始。复制仍按需读取完整题面。
- 本地演示补齐题目详情、比赛目录和积分榜、历史交锋、战绩与回放。CSV 和 JSON 导出返回正确的格式和下载头，贡献数使用页面约定字段。
- 仅演示中将合成记录日期调整到当前 rating 窗口，并补齐合成耗时、内存和题面；原始测试样本保持不变。题面和测评明确标为合成数据，所有写请求继续返回 405。
- 矩阵搜索使用延迟渲染，表格正文及题目行分别记忆化；rating 更新复用未变化的题目行，React 可在行之间让出执行时间。行列高亮按行列索引遍历，避免鼠标移动时扫描所有格子。
- 筛选面板和排名、对比布局按需加载；导航和设置在鼠标靠近或获得焦点时预载，减轻首屏脚本体积。
- 侧栏宽度、内容位置和顶栏同步采用 180ms 短动画；手机导航采用滑入滑出。提示词折叠在支持尺寸插值的浏览器中平滑展开，其余浏览器直接切换。系统减少动态效果时关闭这些过渡。

新增验证命令：`npm --prefix frontend run test:demo`。浏览器验证见 `.verify/browser/report.json`，涵盖风格和主题、刷新保存、侧栏、减少动态效果、250 题提示词分页，以及 1,000 / 10,000 条记录。

## 页面切换与排版细化

- 外壳常驻，路由的懒加载只替换正文；侧栏、顶栏和状态栏不随正文重复挂载。页面正文使用 260ms 淡入与轻微上移；评测视图、排名 / 对比 / 矩阵、比赛分区、设置分类使用 220ms 内容过渡，不通过重挂载实现动画。
- 标题、说明和操作统一分层；统计使用等宽网格，标签与数值上下居中；中等宽度的最后两个统计项平分整行。比赛卡片把状态、名称、说明、评分规则、统计和主要操作分开，引擎版本按需展开。
- 三个评测页签平分可用宽度。取消小屏页签容器的多余滚动区域，避免鼠标悬停页签时纵向滚轮被容器吞掉。
- 分数与 rating 页收起重复矩阵标题和点击说明，布局、筛选、查找与成绩口径共用一条工具栏；筛选面板按需展开。题目与模型数量仅在筛选、查找或隐藏顶部统计后显示，rating 仅在计算、更新区间或出错时显示状态。
- 系统「减少动态效果」和手动关闭动画均生效；过渡被新的切换替代时会取消旧动画，筛选数据更新不触发整个内容区重新播放。
- 新增浏览器专项 `BROWSER_CHECKS=refinement`，覆盖常驻外壳、旧比赛 URL、三种风格的收起 / 刷新 / 展开、状态栏主题、动画偏好保存、减少动态效果，以及 320px + 20px 字号的主要页面。
