# 界面重构与验收

## 约束与基线

- 重构前提交：`c302675`。用户已有的贡献者筛选与 Workers 配置完整保留。
- 游客查阅优先，其次是贡献者；电脑端优先、默认全宽、默认矩阵。
- 保留科技感，减少大圆角、胶囊导航与重复容器；不是移除所有技术风格。
- 不迁移、不导入、不修改真实数据；业务聚合函数、数据库 schema、鉴权接口与主 Workers 配置未改动。
- 本地重构验收阶段未部署、未推送远程、未修改 k4u.top 域名配置；后续发布按用户单独授权执行。

## 界面与操作

- 首次访问默认亮色；顶栏明暗按钮与 T 快捷键直接切换并记住选择。已有暗色/跟随系统偏好继续有效，跟随系统入口保留在「数据与设置 → 外观」。
- 统计从独立卡片改为连续数据带；模型与贡献者筛选合并到同一工具区；公告改为可展开的数据说明。
- 六个分析视图保留，使用带编号与选中底线的标签。标签支持左右方向键及 Home / End。
- 矩阵新增「查找题目」，查询同步到 `mx:q`。它只过滤可见题目行，不改变题目原排名、模型列或底部整体统计。
- 矩阵长模型名可换行；表头与题目列固定；横向溢出留在矩阵内部。成绩可用键盘聚焦并按 Enter / 空格打开详情。
- 成绩图例区分分数与通过状态模式；原有五种单元格统计口径不变。
- 「查找明细」按钮和 F 会展开折叠的明细并聚焦搜索；Ctrl/Cmd+F 不被拦截。
- 登录、账号设置、提交测评、题目发布、历史导入、题目详情统一管理焦点、Esc 与滚动锁。打开弹层时不会触发背后的全局快捷键。
- 原有运行读数收纳到设置菜单，不删除 FPS / 样本数等查看能力。
- 修复原有账号设置接线：昵称与改密使用两个独立表单，避免「修改密码」误调用昵称提交。

## Cloudflare

主部署保持 `wrangler.toml` 和 `npm run deploy`。

可选 Pages 使用 `pages/wrangler.toml`，默认项目名 `ai-vs-luogu-pages`；
`pages/functions/api/[[path]].ts` 原样转发请求到 `API` 服务绑定。
业务由原 `ai-vs-luogu` Worker 执行，保持一套 D1、R2、Cron 与限流。
不要把它理解为不依赖 Worker 的纯 Pages 后端。

Pages 配置必须放在独立目录的标准 `wrangler.toml` 中：当前 Wrangler 的 Pages 命令不支持任意配置文件名。
本地联合测试中 Pages 与 Worker 使用不同名称，避免同名服务解析冲突。

```bash
npm run build
npm --prefix frontend run selftest
npm --prefix frontend run lint
npm --prefix frontend run check-classes
npx tsc --noEmit
npm run e2e
npm run e2e:pages
npm run build:pages
npm run types:pages
npx wrangler deploy --dry-run
```

端到端测试每次创建新的 `.wrangler/e2e-redesign-*` 临时目录，结束后清理。
不会清空或复用 `.wrangler/state`；不要把测试改为使用远程绑定。

## 人工验收建议

1. 用 `npm --prefix frontend run demo` 查看合成样本。页面标题有「合成数据预览」标记，所有写接口禁用。
2. 首次打开为亮色矩阵，切暗色后刷新，确认记忆有效。
3. 查找题号，确认题目行缩小而「整体」分数不变；清除后恢复全部。
4. 聚焦单个模型及贡献者，逐个查看矩阵、雷达、柱状、榜单、滚榜与洞察。
5. 点击成绩打开抽屉，检查提示词、轮次、署名；用 Tab / Shift+Tab / Esc 检查焦点。
6. 查看贡献者与推荐提示词页面；检查桌面和手机窄屏是否出现整页横向溢出。
7. 真实提交/审核/导入等写操作只在隔离测试环境验收，不在只读演示中模拟成功。

构建仍有原项目的单 JS 大包提示；lint 与类名检查存在历史警告，不能把这些输出当作新的业务回归。

## 本轮验证结果

- 前端自检：63/63（含原有聚合口径、权限渲染和新增交互回归）。
- Workers 端到端：57/57。
- Pages → Worker 端到端：57/57。
- 生产前端构建、TypeScript 检查、Pages Functions 编译与 Workers dry-run 通过。
- 浏览器：六种分析视图、模型筛选、矩阵查找、详情抽屉、明暗记忆、登录焦点循环与 Esc 通过；390px 窄屏及 1440px 桌面无整页横向溢出。
- 视觉截图工具的云服务认证失败，自动语义看图未完成；浏览器检查以实际操作、DOM 和尺寸为依据，最终视觉风格仍请用户验收。
