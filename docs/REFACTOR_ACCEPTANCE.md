# v3.17 重构与验收

## 当前入口

首页保留 AI 分数、rating、测评明细、比赛四个页签，默认 rating；`v` 参数保存页签，切换页签进入浏览器历史。
`/v2` 是首页兼容入口，`/old` 跳回首页。旧雷达、柱状、榜单、滚榜、洞察组件保留独立测试，不恢复站点入口。
手机默认排名列表，支持最多三个模型逐题对比；桌面默认二维矩阵。`mx:layout`、`mx:mode`、`mx:q` 保存布局、口径和题目搜索。
矩阵按全部题目自然展开，纵向随页面滚动，只保留模型列的内部横向滚动条；不限制矩阵高度、不做行虚拟化。

原始分包括全部历史；加权分和 rating 保留 `2026-09-05T13:19:00Z` 的创建时间截点。编辑表单始终使用原始记录。
所有统计保持“已审核、题目和模型均已收录”的可见规则；无分数轮次不按零分计入均分。待审归属只依据 `authorId`。

## 增量 Rating

- 每个计算范围维护记录指纹、模型/题目格子和题目内对局。新快照相同则直接复用；无关元数据变化不拟合。
- 格子变化先减旧边贡献再加新边贡献，精确更新胜势积分和模型间对局数。
- Bradley–Terry 先验为 0.3，锚点 1000，尺度 400。连续三轮最大分数变化小于 0.0001 Elo 收敛。
- 复用旧强度最多 2000 轮；未收敛则从强度 1 冷启动最多 10000 轮。失败提供重试，不发布未收敛结果。
- 对局图不变时复用 200 份 bootstrap 抽样次数和统计；图变化时重新均匀有放回抽样。采样随机种子固定，以便重复验证。
- 点估计先更新，95% 区间随后更新。旧区间在新任务期间不显示为当前区间，过期任务不覆盖新范围。
- 缓存按 epoch、算法版本、筛选范围和口径隔离。只有公开默认范围的检查点写入 IndexedDB；内存预算超限时确定性重算。
- 计算留在浏览器后台线程，网络继续使用完整轻量快照与 ETag。模型或贡献者筛选改变评级范围；题目搜索、主题与悬停不改变评级输入。

## 接口与迁移

`GET /api/data?view=compact` 返回 `epoch/revision/scope`，题目目录省略 `content`，附 `hasContent/hasPrompt`。
`GET /api/problems/:pid` 返回完整已发布题目。复制、详情和编辑先补拉题面；原默认 `/api/data` 和导出接口保持完整。
ETag 按身份与响应形状隔离，使用 `private, no-cache` 和 `Vary: Cookie`。持久缓存只含公开已审核数据，旧混合缓存清理。
比赛榜单和交锋统计基于完整历史，列表独立支持 `limit/cursor`，写入原子更新比赛修订号。数据库只做加法迁移，补列后建索引。
比赛目录、详情、分页列表与交锋接口按修订号及查询形状提供 ETag；无变化先读修订号返回 304，积分 memo 按数据库对象隔离并限制为 16 项。
播放器维护源仍在裁判项目的 `kaggriculture/organizer/viz/player.html`，通过原同步脚本生成站点三份静态文件。

## 本次性能结果

2026-10-01，Node.js 24.14.0、Windows 本地生产构建。评分每档重复 5 次，均使用 200 次 bootstrap，以下为中位数；题面等描述字段不参与计分。

| 样本 | 冷启动点估计 / 区间 | 修改一个格子点估计 / 区间 | 新增比较边点估计 / 区间 |
| --- | --- | --- | --- |
| 线上公开数据经时间线与审核过滤：117 条记录、58 条边 | 0.56 / 12.10 ms | 0.71 / 5.53 ms | 0.24 / 18.69 ms |
| 合成 34 模型 × 11 题，6171 条边 | 6.05 / 248.89 ms | 3.36 / 43.07 ms | 1.29 / 263.87 ms |
| 合成 10000 条记录、50 模型 × 200 题，245000 条边 | 332 / 6439 ms | 9.68 / 6694 ms | 40.06 / 6554 ms |

大图的 bootstrap 状态超过 32 MB 保留预算，因此区间在后台确定性重采样全部 200 次；输入、格子、边和点估计仍走增量。
旧同步实现的 34×11 合成全套计算约 1 秒，且占用页面主线程。新实现改变为收敛求解，旧新耗时并非相同迭代次数的比较。
浏览器使用合成 API 与本地 Edge 的测试报告在 `.verify/browser/report.json`，不等同线上用户体验或手机实机性能。
最终验证：Workers 和 Pages 各 198 项，前端自检 74 项，评分引擎 13 项，浏览器 29 项全部通过；类型检查和构建通过，lint 无错误但保留 Hook 等警告。
浏览器 5 次 LCP 中位数 84 ms、CLS 最大 0.000504、自动交互 p95 约 74 ms；初始界面 JavaScript gzip 99375 字节，评分 Worker 单列 4860 字节。
初次重构时，1000/10000 条浏览器样本的虚拟矩阵分别挂载 19/27 行，输入 p95 为 58/75 ms。后续按用户要求取消矩阵内部竖向滚动和行虚拟化，改为全部题目自然展开；该挂载行数不再代表当前布局。回放连续 60 帧同步 JavaScript render 的 p95 约 0.8 ms，未包含浏览器绘制或 GPU 时间。
